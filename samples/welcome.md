# View MD

A quick Markdown viewer for macOS.

## Features

- Open `.md` and `.markdown` files.
- Preview rendered Markdown.
- Switch to generated HTML source.
- Copy the HTML output.

| Shortcut | Action |
| --- | --- |
| `Cmd+O` | Open Markdown |
| `Cmd+Shift+H` | Toggle Preview / HTML |
| `Cmd+Shift+C` | Copy HTML |
